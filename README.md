# Trabalho-Madleine-e-Miguel-V2

Este projeto consiste no desenvolvimento de um site com o objetivo de mostrar o que aprendemos durante as aulas de Desenvolvimento Web. A proposta desse site é apresentar uma loja de discos de vinil fictícia, utilizando a linguagem HTML para a formação da estrutura do site e o CSS para os elementos visuais relacionados ao tema escolhido.

Os alunos fizeram uso dos aplicativos VS Code (Visual Studio Code), para escrever o código nas linguagens HTML e CSS; GitHub, para o compartilhamento do desenvolvimento do trabalho e para uma melhor análise do professor; Live Server, para que fosse possível visualizar o site durante sua criação; Google, para a pesquisa de algumas informações e busca de imagens; WhatsApp, para a comunicação; e Spotify, para um dos links adicionados ao site.
